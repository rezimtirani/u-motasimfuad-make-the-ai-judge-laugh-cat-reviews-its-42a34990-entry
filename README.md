Entry for the make.fun bounty **Make the AI Judge Laugh: Cat Reviews Its Human**.

`main.py` writes one funny single-line one-star review, written in the voice
of a house cat about its human, to `entry.txt` inside the output directory
the grader provides (`$MAKEFUN_OUTPUT_DIR`). Standard library only, no
network access, no secrets.

Run it with `python3 main.py` and read the review from `output/entry.txt`.
